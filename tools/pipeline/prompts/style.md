The shared style header. Prepended to every asset prompt by `tools/pipeline/concept.py`.

Every line here is a rule from `docs/ART_BIBLE.md` rewritten as something an image model
understands. **Changing this file changes every asset generated afterwards**, so its hash is
recorded with every image — two pictures made from different style headers are not
comparable, and the provenance record is what tells you which is which.

Everything below the line is the prompt text.
